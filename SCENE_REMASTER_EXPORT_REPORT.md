# Scene MOP/CUT remaster-ready export

Date: 2026-07-15

## Deliverable

The deterministic export is in `remaster-export/` and is generated by
`ac6-scene-remaster-export`. It contains 1,838 files occupying approximately
23 MiB:

- 553 `mop/NNNN/raw.mop` untouched resource payloads;
- 553 `mop/NNNN/gyz.bin` bounded GYZ regions;
- 553 `mop/NNNN/records.csv` fixed-stride record tables with all twelve
  big-endian words preserved;
- 44 `cut/NNNN/raw.nfic-cut` untouched state payloads;
- per-CUT `chunks.csv`, `events.csv`, and `symbols.csv` structured exports;
- `relations.csv`, joining every MOP to its Scene path, record index, FHM path,
  CUT, source offsets, sizes, and raw CRC32 values;
- `files.csv`, recording every generated asset's kind, size, CRC32, source
  entry and source span;
- `provenance.csv`, recording decoded DATA.TBL entry 9, its size, CRC32
  `3c68af05`, and export cardinalities.

The first relation maps MOP index 0 to CUT index 0 and
`Scene/dd01_01a/dd01_01a_01/Tcam__c01.mop`, preserving its entry-9 offsets and
checksums.

## Determinism

The GCC sanitizer export, an independent repeat export, and the Clang sanitizer
export compared recursively identical. A sorted SHA-256 digest over every
relative filename plus file content produced the same tree digest for all
three:

`bbea9fa33df1e4687da7b171df78ad4cf63bfff71ac4358c3da1d4311ffd371c`.

The output directory must be absent or empty, preventing accidental mixing
with stale assets. Source names are stored as CSV data; generated filesystem
names use deterministic numeric indices and cannot escape the export root.

## Remaster boundary

This export is ready for subsequent inspection, visualization, editing and
replacement workflows while keeping raw source payloads available for exact
comparison. It does not yet convert neutral GYZ words into camera curves or
rendered frames, and it does not modify proprietary assets.

## Validation

- GCC ASan+UBSan: 13/13 tests passed and complete export executed;
- Clang ASan+UBSan: 13/13 tests passed and complete export executed;
- the two compiler outputs and independent repeat are byte-identical;
- Windows compilation is non-blocking for this Linux-first slice.
