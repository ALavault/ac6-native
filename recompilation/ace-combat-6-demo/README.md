# AC6 PAL demo native runtime archive

This directory is a historical analysis archive. The hand-written PAL demo
runtime was retired after cycle 1850 reached tick 5811 and stopped on an
unsupported Xenos form. It is not an active product, must not be built or run,
and its old binaries, caches, reports, captures and artifacts are not reusable
as retail-product validation.

The retained files are limited to target qualification, static manifests,
offline cross-match utilities and Ghidra scripts. The canonical demo project is
`ghidra-projects/ace-combat-6-demo`; it remains distinct from the canonical PAL
retail project `ghidra-projects/ace-combat-6`.

The active product is `../ace-combat-6-retail`, bootstrapped with the qualified
NTSC-U/J retail XEX before the final PAL retail port.
